# Minecraft-x-Isaac-Skin-Tool

Download and extract the ZIP, then place the entire custom_skins folder inside your installed mcxisaac_steve mod folder. Close the game, run Apply Skin.exe, choose your skin and the matching Steve/Alex model, apply it, then restart the game.  
下载并解压，将整个 custom_skins 文件夹放入已安装的 mcxisaac_steve Mod 文件夹。关闭游戏，运行 Apply Skin.exe，选择皮肤和对应的宽／细手臂模型，应用后重启游戏。
